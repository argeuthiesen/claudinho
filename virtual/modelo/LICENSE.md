# Case 3D files / Arquivos 3D da caixa

**English.** The files in this folder (`corpo.stl`, `moldura.stl`,
`base.stl`) are the 3D-printed case of the single-board Claudinho, modeled by
hand by Argeu Thiesen. They are here only so the virtual Claudinho can draw
the case in the browser. **They are not covered by this repository's MIT
license:** they follow the same license as the model on
[MakerWorld](https://makerworld.com/models/3365275-claudinho), where you
should download them to print.

**Português.** Os arquivos desta pasta (`corpo.stl`, `moldura.stl`,
`base.stl`) são a caixa impressa em 3D do Claudinho de placa única, modelada
à mão por Argeu Thiesen. Estão aqui só para o Claudinho virtual desenhar a
caixa no navegador. **Eles não estão sob a licença MIT deste repositório:**
seguem a mesma licença do modelo no
[MakerWorld](https://makerworld.com/models/3365275-claudinho), de onde você
deve baixá-los para imprimir.
